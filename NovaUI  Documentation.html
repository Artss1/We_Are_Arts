Начало работы

Шаг 1
Загрузка библиотеки
Используйте loadstring для загрузки NovaUI в ваш скрипт.
local NovaUI = loadstring(game:HttpGet("https://raw.githubusercontent.com/NovaUI/NovaUI/main/source.lua"))()
Шаг 2
Параметры CreateWindow
Создайте главное окно NovaUI с нужными настройками.

Шаг 3
Создание вкладки (CreateTab)
Добавьте вкладки для организации элементов.
local Tab = Window:CreateTab({
    Name = "Главная",
    Icon = "rbxassetid://7733960981"
})
Полный пример
Рабочий скрипт
Полноценный пример создания окна с несколькими элементами.
local NovaUI = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/NovaUI/NovaUI/main/source.lua"
))()

local Window = NovaUI:CreateWindow({
    Title = "Мой скрипт",
    SubTitle = "by Developer",
    Theme = "Dark",
    Size = UDim2.new(0, 560, 0, 420),
    Draggable = true,
    Minimizable = true,
    Closable = true
})

local MainTab = Window:CreateTab({
    Name = "Главная"
})

MainTab:CreateButton({
    Name = "Нажми меня",
    Callback = function()
        print("Кнопка нажата!")
    end
})

local Toggle = MainTab:CreateToggle({
    Name = "Включить функцию",
    Default = false,
    Callback = function(value)
        print("Toggle:", value)
    end
})

Элементы NovaUI

Все доступные элементы интерфейса с примерами кода и описанием методов.

▤ Section Element
Создаёт визуальный раздел для группировки элементов внутри вкладки.
local Section = Tab:CreateSection("Настройки")
𝐓 Text Element :Set()
Отображает динамический текст. Метод :Set(text) обновляет содержимое.
local Text = Tab:CreateText({
    Name = "Статус",
    Text = "Ожидание..."
})
Text:Set("Активно!")
¶ Paragraph Element
Отображает многострочный абзац текста с заголовком.
Tab:CreateParagraph({
    Title = "О скрипте",
    Content = "Этот скрипт автоматизирует фарм ресурсов."
})
─ Divider Element
Горизонтальный разделитель для визуального разграничения групп элементов.
Tab:CreateDivider()
⬡ Button Element :SetText()
Кликабельная кнопка с функцией обратного вызова. :SetText(text) меняет надпись.
local Btn = Tab:CreateButton({
    Name = "Запустить",
    Callback = function()
        print("Нажато!")
    end
})
Btn:SetText("Остановить")
⏻ Toggle Element :Set() :Get()
Переключатель вкл/выкл. :Set(bool) устанавливает значение, :Get() возвращает текущее.
local Toggle = Tab:CreateToggle({
    Name = "Авто-фарм",
    Default = false,
    Callback = function(value)
        print("Состояние:", value)
    end
})
Toggle:Set(true)
print(Toggle:Get()) -- true
⇔ Slider Element :Set() :Get()
Ползунок для выбора числового значения в диапазоне. Поддерживает дробные значения.
local Slider = Tab:CreateSlider({
    Name = "Скорость",
    Min = 16,
    Max = 200,
    Default = 16,
    Increment = 1,
    Callback = function(value)
        game.Players.LocalPlayer.Character
            .Humanoid.WalkSpeed = value
    end
})
Slider:Set(50)
print(Slider:Get()) -- 50
☑ Checkbox Element
Флажок для выбора булевого значения, аналог Toggle с другим визуальным стилем.
Tab:CreateCheckbox({
    Name = "Показать HUD",
    Default = true,
    Callback = function(value)
        print("Checkbox:", value)
    end
})
▽ Dropdown Element :Set() :Get() :Refresh()
Выпадающий список. :Refresh(options) обновляет список опций динамически.
local DD = Tab:CreateDropdown({
    Name = "Оружие",
    Options = {"Меч", "Лук", "Посох"},
    Default = "Меч",
    Callback = function(value)
        print("Выбрано:", value)
    end
})
DD:Set("Лук")
print(DD:Get())
DD:Refresh({"Меч", "Лук", "Посох", "Кинжал"})
▭ TextBox Element :Set() :Get()
Поле ввода текста. Поддерживает плейсхолдер, очистку по Enter.
local TB = Tab:CreateTextBox({
    Name = "Имя игрока",
    Placeholder = "Введите имя...",
    ClearOnFocus = true,
    Callback = function(value)
        print("Введено:", value)
    end
})
TB:Set("PlayerName")
print(TB:Get())
⌨ Keybind Element :Set() :Get()
Привязка клавиши. Игрок нажимает кнопку и затем нажимает нужную клавишу.
local KB = Tab:CreateKeybind({
    Name = "Открыть меню",
    Default = Enum.KeyCode.RightShift,
    Callback = function(key)
        print("Клавиша:", key)
    end
})
KB:Set(Enum.KeyCode.F)
print(KB:Get())
▬ ProgressBar Element :Set()
Полоса прогресса от 0 до 100. :Set(value) анимированно обновляет заполнение.
local PB = Tab:CreateProgressBar({
    Name = "Загрузка данных",
    Min = 0,
    Max = 100,
    Default = 0
})
PB:Set(75) -- установить 75%
💬 Tooltip :AddTooltip()
Добавляет всплывающую подсказку к любому элементу при наведении курсора.
local Btn = Tab:CreateButton({
    Name = "Действие",
    Callback = function() end
})
Btn:AddTooltip("Нажмите для выполнения действия")
ℹ InfoPanel Element
Информационная панель для отображения статических данных: ключ-значение парами.
Tab:CreateInfoPanel({
    Name = "Информация",
    Data = {
        {Label = "Версия", Value = "1.0.0"},
        {Label = "Автор", Value = "NovaTeam"},
        {Label = "Статус", Value = "Активен"}
    }
})

Темы оформления

NovaUI поставляется с 5 встроенными темами. Переключайтесь между ними одной строкой.

Dark
Тёмный фон + янтарный акцент. По умолчанию.
Midnight
Глубокий синий фон + синий акцент.
Ocean
Тёмно-бирюзовый фон + зелёный акцент.
Sunset
Тёмно-коричневый фон + оранжево-красный акцент.
Light
Белый фон + бирюзовый акцент.

Переключение темы

-- При создании окна
local Window = NovaUI:CreateWindow({
    Title = "Мой скрипт",
    Theme = "Ocean" -- "Dark"|"Midnight"|"Ocean"|"Sunset"|"Light"
})

-- Динамическое переключение
NovaUI:SetTheme("Sunset")

AutoFarm Pro
Farming
by FarmKing
Автоматический фарм ресурсов и опыта с настройкой радиуса и цели.
local NovaUI = loadstring(game:HttpGet("https://raw.githubusercontent.com/NovaUI/NovaUI/main/source.lua"))()
local Win = NovaUI:CreateWindow({Title="AutoFarm Pro",Theme="Dark"})
local Tab = Win:CreateTab({Name="Фарм"})
local farming = false
Tab:CreateToggle({Name="Авто-фарм",Default=false,Callback=function(v)
    farming=v
    if farming then
        game:GetService("RunService").Heartbeat:Connect(function()
            if not farming then return end
            local char = game.Players.LocalPlayer.Character
            if char then
                for _,v in pairs(workspace:GetDescendants()) do
                    if v:IsA("Part") and v.Name == "Resource" then
                        char.HumanoidRootPart.CFrame = v.CFrame
                    end
                end
            end
        end)
    end
end})

ESP / Wallhack
Combat
by VisualPro
Отображение игроков сквозь стены с именами, здоровьем и расстоянием.
local NovaUI = loadstring(game:HttpGet("https://raw.githubusercontent.com/NovaUI/NovaUI/main/source.lua"))()
local Win = NovaUI:CreateWindow({Title="ESP Pro",Theme="Dark"})
local Tab = Win:CreateTab({Name="ESP"})
local espEnabled = false
local highlights = {}
Tab:CreateToggle({Name="ESP Включить",Default=false,Callback=function(v)
    espEnabled = v
    if v then
        for _,plr in pairs(game.Players:GetPlayers()) do
            if plr ~= game.Players.LocalPlayer and plr.Character then
                local h = Instance.new("Highlight")
                h.FillColor = Color3.fromRGB(255,0,0)
                h.Parent = plr.Character
                highlights[plr.Name] = h
            end
        end
    else
        for _,h in pairs(highlights) do h:Destroy() end
        highlights = {}
    end
end})

Aimbot
Combat
by AimGod
Автоприцеливание на ближайшего противника с настройкой плавности и FOV.
local NovaUI = loadstring(game:HttpGet("https://raw.githubusercontent.com/NovaUI/NovaUI/main/source.lua"))()
local Win = NovaUI:CreateWindow({Title="Aimbot",Theme="Dark"})
local Tab = Win:CreateTab({Name="Прицел"})
local aimbotOn = false; local smooth = 0.1
Tab:CreateToggle({Name="Aimbot",Default=false,Callback=function(v) aimbotOn=v end})
Tab:CreateSlider({Name="Плавность",Min=1,Max=100,Default=10,
    Callback=function(v) smooth=v/100 end
})
game:GetService("RunService").Heartbeat:Connect(function()
    if not aimbotOn then return end
    local cam = workspace.CurrentCamera
    local closest,dist = nil, math.huge
    for _,p in pairs(game.Players:GetPlayers()) do
        if p~=game.Players.LocalPlayer and p.Character then
            local d = (p.Character.HumanoidRootPart.Position-cam.CFrame.Position).Magnitude
            if d<dist then closest=p; dist=d end
        end
    end
    if closest then
        cam.CFrame = cam.CFrame:Lerp(CFrame.lookAt(cam.CFrame.Position,
            closest.Character.HumanoidRootPart.Position),smooth)
    end
end)

Методы элементов

Toggle:Set(value) / Toggle:Get() ›

Программно устанавливает или получает состояние переключателя.

local t = Tab:CreateToggle({Name="Функция",Default=false,Callback=function(v) end})
t:Set(true)          -- включить
t:Set(false)         -- выключить
print(t:Get())        -- false
Slider:Set(value) / Slider:Get() ›

Устанавливает или возвращает числовое значение ползунка.

local s = Tab:CreateSlider({Name="Скорость",Min=0,Max=100,Default=50,Callback=function(v) end})
s:Set(75)
print(s:Get())  -- 75
Dropdown:Set(option) / Dropdown:Get() / Dropdown:Refresh(options) ›

Управление выпадающим списком: выбор значения, получение текущего, обновление опций.

local dd = Tab:CreateDropdown({Name="Оружие",Options={"Меч","Лук"},Callback=function(v) end})
dd:Set("Лук")
print(dd:Get())          -- "Лук"
dd:Refresh({"Меч","Лук","Кинжал"})  -- обновить список
TextBox:Set(text) / TextBox:Get() ›

Программная установка и получение текста из поля ввода.

local tb = Tab:CreateTextBox({Name="Имя",Callback=function(v) end})
tb:Set("PlayerOne")
print(tb:Get())   -- "PlayerOne"
ProgressBar:Set(value) ›

Анимированное обновление значения прогресс-бара (0–100).

local pb = Tab:CreateProgressBar({Name="Загрузка",Min=0,Max=100,Default=0})
for i = 1, 100 do
    pb:Set(i)
    task.wait(0.05)
end
Button:SetText(text) ›

Изменяет надпись кнопки динамически без пересоздания элемента.

local btn = Tab:CreateButton({Name="Запуск",Callback=function() end})
btn:SetText("Остановить")
task.wait(3)
btn:SetText("Запуск")
element:AddTooltip(text) ›

Добавляет всплывающую подсказку к любому элементу. Вызывается на возвращённом объекте элемента.

local btn = Tab:CreateButton({Name="Действие",Callback=function() end})
btn:AddTooltip("Нажмите для выполнения действия над игроком")

local toggle = Tab:CreateToggle({Name="Функция",Default=false,Callback=function(v) end})
toggle:AddTooltip("Включает или отключает функцию автоматически")
